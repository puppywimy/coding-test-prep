### 문제 분석 요약
단순 정렬 문제

### 알고리즘 설계
조건
- 1 <= N <= 1,000, |각 수| <= 1,000

단순 오름차순 정렬 문제로 내장 메소드를 이용하여 풀이

### 코드
```py
# 제출 시 파일 입출력 부분 지우기

import sys

sys.stdin = open("input", "r")


def solution():
    N = int(input())
    numbers = [int(input()) for _ in range(N)]
    numbers.sort()
    print("\n".join(map(str, numbers)))


solution()
```

### 시간 복잡도
O(NlogN)

### 느낀점 or 기억할 정보
- Python의 list.sort()는 Timsort로 구현되어 있어 O(NlogN)의 시간 복잡도를 가지며, 최적화가 잘 되어있다.
- 쉬운 문제더라도 한 번 더 확인하고 제출하는 연습을 하자. (`print(numbers)`로 제출해버림.)
