### 문제 및 풀이 날짜

- https://www.acmicpc.net/problem/2230
- 2025-10-20

### 문제 분석 요약

투포인터를 이용해 두 수의 특정 값 이상이 되는 차이 중 최솟값 탐색

### 제한사항

- 1 <= N <= 100,000
- 0 <= M <= 2,000,000,000
- 0 <= |A[i]| <= 1,000,000,000

### 알고리즘 설계

수열을 정렬한 뒤, 투포인터를 이용하여 최솟값을 찾고자 했다.

정렬의 시간 복잡도는 NlogN = 1,700,000이고, 투포인터를 이용한 탐색 시간 복잡도는 2N = 200,000이므로 대략 2,000,000 정도가 된다.<br />
따라서 이 방법으로 안전하게 풀 수 있다.

### 코드

```py
def solution():
    N, M = map(int, input().split(" "))
    sortedNumbers = sorted([int(input()) for _ in range(N)])
    pointer1 = 0
    pointer2 = 0
    minimum = sortedNumbers[-1] - sortedNumbers[0]
    while pointer2 < N:
        if sortedNumbers[pointer2] - sortedNumbers[pointer1] < M:
            pointer2 += 1
        elif sortedNumbers[pointer2] - sortedNumbers[pointer1] > M:
            if sortedNumbers[pointer2] - sortedNumbers[pointer1] < minimum:
                minimum = sortedNumbers[pointer2] - sortedNumbers[pointer1]
            pointer1 += 1
        else:
            print(M)
            return
    print(minimum)


solution()
```

### 시간 복잡도

**O(NlogN)**<br />
정렬하는 시간 복잡도가 가장 크기 때문에(O(NlogN) > O(N))
