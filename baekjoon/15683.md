### 문제 분석 요약
백트래킹을 이용하여 모든 경우의 수를 확인하고 최솟값을 찾는 문제

### 알고리즘 설계
조건
- 1 <= N, M <= 8, 0 <= CCTV 개수 < 8
- CCTV는 벽 넘어를 감시할 수 **없다.**
- CCTV끼리는 통과할 수 **있다.**

문제가 워낙 복잡해 그냥 경우의 수를 모두 구하고 최솟값을 찾는 전수조사 방식으로 구해보고자 했다.<br />
그러기 앞서 시간 복잡도를 계산해보니,
- 사각지대 크기 계산: N * M = **64**
- 모든 CCTV를 4방향으로 돌렸을 때 경우의 수: 4^8 = **약 65,000**
- 각 방향으로 감시되는 지역을 표시하는 최대 시간 복잡도: 7(변의 최대 길이 - 1) * 4(방향) = **28**

모두 곱하면 대충 **1억**이 조금 넘어서 해볼만하다고 판단했다.<br />
복잡한 경우를 읽기 쉽게 구현하기 위해 백트래킹으로 구현하고자 하였고,<br />
각 재귀함수에 복사된 맵을 전달함으로써 시간 복잡도를 줄이려했다. (공간 복잡도: N * M * {경우의 수} = 약 4,000,000, 16MB?)

1. **함수 정의**
   ```js
   const cctvs = [
     {
       type: '1' | '2' | '3' | '4' | '5',
       position: [i, j], // position을 시작으로 레이트레이싱?을 할 예정
     },
   ]
   let min = N * M;
   
   function recursive(index, map) { /* ... */ }
   ```
2. **Base Condition**

   현재 cctv 인덱스가 N과 같다면 마지막 cctv까지 탐색을 완료한 경우<br />
   이때 사각지대의 계산 결과가 min보다 작다면 최솟값 업데이트
4. **재귀 식**
   ```js
   function recursive(index, map) {
       Base Condition

       cctvs[index]의 종류에 따라 맵을 몇번(방향 개수) 업데이트할 것인지 결정
       방향별로 업데이트 후
       recursive(index + 1, newMap)
   }
   ```

### 코드
```js
const fs = require("fs");
const rawInput = fs.readFileSync("input").toString().trim(); // fs.readFileSync(0, "utf-8").trim();

function solution() {
  const [[N, M], ...map] = rawInput.split("\n").map((row) => row.split(" "));
  const cctvs = [];
  for (let i = 0; i < N; i++) {
    for (let j = 0; j < M; j++) {
      if (map[i][j] === "0" || map[i][j] === "6") continue;
      cctvs.push({
        type: map[i][j],
        position: [i, j],
      });
    }
  }
  let min = N * M;

  function getSizeOfBlindSpot(map) {
    let count = 0;
    for (let i = 0; i < N; i++) {
      for (let j = 0; j < M; j++) {
        if (map[i][j] === "0") count++;
      }
    }
    return count;
  }

  function recursive(index, map) {
    if (index === cctvs.length) {
      const sizeOfBlindSpot = getSizeOfBlindSpot(map);
      if (sizeOfBlindSpot < min) min = sizeOfBlindSpot;
      return;
    }

    switch (cctvs[index].type) {
      case "1": {
        // 상, 우, 하, 좌
        const dx = [0, 1, 0, -1];
        const dy = [-1, 0, 1, 0];
        for (let j = 0; j < 4; j++) {
          const newMap = map.map((row) => row.map((element) => element));
          let step = 1;
          let newX = cctvs[index].position[1] + dx[j] * step;
          let newY = cctvs[index].position[0] + dy[j] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] + dx[j] * step;
            newY = cctvs[index].position[0] + dy[j] * step;
          }
          recursive(index + 1, newMap);
        }
        break;
      }
      case "2": {
        // 상, 좌
        const dx = [0, -1];
        const dy = [-1, 0];
        for (let j = 0; j < 2; j++) {
          const newMap = map.map((row) => row.map((element) => element));
          let step = 1;
          let newX = cctvs[index].position[1] + dx[j] * step;
          let newY = cctvs[index].position[0] + dy[j] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] + dx[j] * step;
            newY = cctvs[index].position[0] + dy[j] * step;
          }
          step = 1;
          newX = cctvs[index].position[1] - dx[j] * step;
          newY = cctvs[index].position[0] - dy[j] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] - dx[j] * step;
            newY = cctvs[index].position[0] - dy[j] * step;
          }
          recursive(index + 1, newMap);
        }
        break;
      }
      case "3": {
        // 상, 우, 하, 좌
        const dx = [0, 1, 0, -1];
        const dy = [-1, 0, 1, 0];
        for (let j = 0; j < 4; j++) {
          const newMap = map.map((row) => row.map((element) => element));
          let step = 1;
          let newX = cctvs[index].position[1] + dx[j] * step;
          let newY = cctvs[index].position[0] + dy[j] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] + dx[j] * step;
            newY = cctvs[index].position[0] + dy[j] * step;
          }
          step = 1;
          newX = cctvs[index].position[1] + dx[(j + 1) % 4] * step;
          newY = cctvs[index].position[0] + dy[(j + 1) % 4] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] + dx[(j + 1) % 4] * step;
            newY = cctvs[index].position[0] + dy[(j + 1) % 4] * step;
          }
          recursive(index + 1, newMap);
        }
        break;
      }
      case "4": {
        // 상, 우, 하, 좌
        const dx = [0, 1, 0, -1];
        const dy = [-1, 0, 1, 0];
        for (let j = 0; j < 4; j++) {
          const newMap = map.map((row) => row.map((element) => element));
          let step = 1;
          let newX = cctvs[index].position[1] + dx[j] * step;
          let newY = cctvs[index].position[0] + dy[j] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] + dx[j] * step;
            newY = cctvs[index].position[0] + dy[j] * step;
          }
          step = 1;
          newX = cctvs[index].position[1] + dx[(j + 1) % 4] * step;
          newY = cctvs[index].position[0] + dy[(j + 1) % 4] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] + dx[(j + 1) % 4] * step;
            newY = cctvs[index].position[0] + dy[(j + 1) % 4] * step;
          }
          step = 1;
          newX = cctvs[index].position[1] + dx[(j + 2) % 4] * step;
          newY = cctvs[index].position[0] + dy[(j + 2) % 4] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] + dx[(j + 2) % 4] * step;
            newY = cctvs[index].position[0] + dy[(j + 2) % 4] * step;
          }
          recursive(index + 1, newMap);
        }
        break;
      }
      case "5": {
        // 상, 우, 하, 좌
        const dx = [0, 1, 0, -1];
        const dy = [-1, 0, 1, 0];
        const newMap = map.map((row) => row.map((element) => element));
        for (let j = 0; j < 4; j++) {
          let step = 1;
          let newX = cctvs[index].position[1] + dx[j] * step;
          let newY = cctvs[index].position[0] + dy[j] * step;
          while (
            0 <= newX &&
            newX < M &&
            0 <= newY &&
            newY < N &&
            newMap[newY][newX] !== "6" // CCTV는 CCTV를 통과할 수 있다.
          ) {
            newMap[newY][newX] = "#";
            step++;
            newX = cctvs[index].position[1] + dx[j] * step;
            newY = cctvs[index].position[0] + dy[j] * step;
          }
        }
        recursive(index + 1, newMap);
        break;
      }
    }
  }

  recursive(0, map);
  console.log(min);
}

solution();
```

### 시간 복잡도
O(4^{CCTV 수} * (N + M)), 모든 경우를 탐색하며 (N + M)만큼 맵을 업데이트하기 때문
