### 문제 분석 요약

BFS를 이용하여 도형의 둘레 구하기

### 알고리즘 설계

조건

- 도화지의 크기: 100 \* 100
- 색종이의 크기: 10 \* 10
- 1 <= 색종이의 개수 <= 100

<br />

색종이를 모두 붙여놓고 BFS로 가장자리를 탐색할 때마다 둘레 값을 1씩 증가시키는 방법을 고안함.<br />
(네 방향을 탐색하기 때문에 각 방향이 비어있는지를 확인하면 둘레 값을 구할 수 있을 것 같았다.)

시간 복잡도를 계산해보면

1. 색종이 칠하기: 색종이의 크기 \* 개수 = 10 \* 10 \* 100 = 10,000
2. 칠한 영역 BFS: 이미 탐색한 곳을 탐색하지 않으므로 10,000

10,000 + 10,000 = 20,000 이므로 이 방법으로 안전하게 풀 수 있음.

### 코드

```py
from collections import deque


def solution():
    coloredPaperCount = int(input())
    drawingPaper = [[0 for _ in range(100)] for _ in range(100)]
    perimeter = 0

    # 도화지에 색종이 채우기
    for _ in range(coloredPaperCount):
        firstI, firstJ = map(int, input().split(" "))
        for i in range(firstI, firstI + 10):
            for j in range(firstJ, firstJ + 10):
                drawingPaper[i][j] = 1

    # BFS로 둘레 구하기
    for i in range(100):
        for j in range(100):
            if drawingPaper[i][j] == 0 or drawingPaper[i][j] == 2:
                continue
            queue = deque([[i, j]])
            drawingPaper[i][j] = 2
            dx = [-1, 1, 0, 0]
            dy = [0, 0, -1, 1]
            while len(queue):
                x, y = queue.popleft()
                for k in range(4):
                    newX, newY = x + dx[k], y + dy[k]
                    if (
                        not (0 <= newX and newX < 100 and 0 <= newY and newY < 100)
                        or drawingPaper[newX][newY] == 0
                    ):
                        perimeter += 1
                        continue
                    if drawingPaper[newX][newY] == 2:
                        continue
                    queue.append([newX, newY])
                    drawingPaper[newX][newY] = 2

    print(perimeter)


solution()
```
