### 문제 분석 요약
재귀를 이용하여 시간 복잡도 줄이기
### 알고리즘 설계
조건: 1 <= A, B, C <= 2,147,483,647, 시간 제한 0.5초

A를 B번 곱하면 O(약 21억)이므로 시간 초과 발생

따라서 수학적 귀납법을 활용하여 재귀 함수 설계
1. A^1은 O(1)의 시간복잡도로 구할 수 있다.
2. A^n을 구할 수 있으면 A^2n도 O(1)의 시간복잡도로 구할 수 있다. 왜냐하면, A^2n = A^n * A^n
3. A^n을 구할 수 있으면 A^2n+1도 O(1)의 시간복잡도로 구할 수 있다. 왜냐하면, A^2n+1 = A^n * A^n * A
4. Base Condition: n이 1일 때 탈출

주의 사항
1. A의 곱셈은 Number.MAX_SAFE_INTEGER보다 커질 수 있으므로 BigInt로 처리
2. BigInt를 사용하더라도 메모리 문제로 C로 계속 나머지 연산을 해주어야 함.

### 코드
```js
const fs = require("fs");
const rawInput = fs.readFileSync("input").toString().trim(); // fs.readFileSync(0, "utf-8").trim();

function solution() {
  const [A, B, C] = rawInput.split(" ").map(BigInt);

  function recursive(index) {
    if (index === 1) return A % C;
    const temp = recursive(Math.floor(index / 2));
    if (index % 2 === 0) return (temp * temp) % C;
    return (((temp * temp) % C) * A) % C;
  }

  console.log(Number(recursive(Number(B))));
}

solution();
```

### 시간 복잡도
O(logB), B가 계속 절반으로 줄기 때문
