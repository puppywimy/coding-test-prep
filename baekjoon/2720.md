### 문제 분석 요약
큰 수부터 이용해 나누는 그리디 알고리즘 문제 

### 알고리즘 설계
조건
- 1 <= 거스름돈 C <= 500

쿼터부터 작아지는 순서대로 거스름돈을 나누면 동전의 개수를 최소로 만들 수 있다.

### 코드
```js
const fs = require("fs");
const rawInput = fs.readFileSync("input").toString().trim(); // fs.readFileSync(0, "utf-8").trim();

function solution() {
  const [T, ...changes] = rawInput.split("\n").map(Number);
  for (let i = 0; i < T; i++) {
    let change = changes[i];
    const coins = [];

    const quarter = Math.floor(change / 25);
    coins.push(quarter);
    if (quarter > 0) change %= 25;

    const dime = Math.floor(change / 10);
    coins.push(dime);
    if (dime > 0) change %= 10;

    const nickel = Math.floor(change / 5);
    coins.push(nickel);
    if (nickel > 0) change %= 5;

    const penny = Math.floor(change / 1);
    coins.push(penny);
    if (penny > 0) change %= 1;

    console.log(coins.join(" "));
  }
}

solution();
```

### 시간 복잡도
O(1), 각 테스트 케이스에 대해 나누는 연산만 존재
