### 문제 분석 요약

탐색 문제

### 알고리즘 설계

조건

- 8 <= brown <= 5,000
- 1 <= yellow <= 2,000,000
- 세로 <= 가로

<br />

우선 yellow가 나올 수 있는 두 수의 곱 조합을 찾아 brown과 비교해보는 방법으로 풀고자 했음.<br />
[1, sqrt(2000000)]의 범위를 탐색하며 곱 조합을 찾아내면 되므로, 시간 복잡도는 O(sqrt(yellow))로 대략 1,400<br />
즉, 이 방법으로 안전하게 풀 수 있음.

### 코드

```py
import math


def solution(brown, yellow):
    for innerHeight in range(1, math.floor(math.sqrt(yellow)) + 1):
        if yellow % innerHeight != 0:
            continue
        innerWidth = yellow // innerHeight
        width = innerWidth + 2
        height = innerHeight + 2
        border = (width + height - 2) * 2
        if border == brown:
            return [width, height]
```

### 시간 복잡도

**O(sqrt(yellow))**<br />
yellow를 만들 수 있는 두 수의 곱 조합을 찾는 것이기 때문
