### 문제 분석 요약

테이블이 2차원인 DP 문제

### 제한사항

- 행의 개수 N : 100,000 이하의 자연수
- 열의 개수는 4개이고, 땅(land)은 2차원 배열로 주어집니다.
- 점수 : 100 이하의 자연수

### 알고리즘 설계

바로 전에 선택한 값에 따라 선택지가 좁아져 테이블이 2차원인 DP를 이용하여 풀 수 있을 것이라 생각했다.<br />
시간 복잡도는 O(N) = 100,000 이므로 안전하게 풀 수 있다.

1. 테이블 정의

   ```
   D[i][c] = i행에서 c열을 선택했을 때, 지금까지의 합 최댓값
             단, c열을 연속해서 선택할 수 없음.

   D[i][0] = max(D[i - 1][1], D[i - 1][2], D[i - 1][3]) + land[i][0]
   D[i][1] = ...
   D[i][2] = ...
   D[i][3] = ...
   ```

2. 초기값

   D[0][c] = land[0][c]

마지막에 max(D[len(D) - 1][0], D[len(D) - 1][1], D[len(D) - 1][2], D[len(D) - 1][3])을 반환해주면 된다.

### 코드

```py
def solution(land):
    table = [[None, None, None, None] for _ in range(len(land))]
    table[0] = land[0]
    for i in range(1, len(land)):
        table[i][0] = (
            max(table[i - 1][1], table[i - 1][2], table[i - 1][3]) + land[i][0]
        )
        table[i][1] = (
            max(table[i - 1][0], table[i - 1][2], table[i - 1][3]) + land[i][1]
        )
        table[i][2] = (
            max(table[i - 1][0], table[i - 1][1], table[i - 1][3]) + land[i][2]
        )
        table[i][3] = (
            max(table[i - 1][0], table[i - 1][1], table[i - 1][2]) + land[i][3]
        )
    return max(table[len(table) - 1])
```

### 시간 복잡도

**O(N)**
