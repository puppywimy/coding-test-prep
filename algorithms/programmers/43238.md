### 문제 분석 요약

이분 탐색 문제

### 제한 사항

- 입국심사를 기다리는 사람은 1명 이상 1,000,000,000명 이하입니다.
- 각 심사관이 한 명을 심사하는데 걸리는 시간은 1분 이상 1,000,000,000분 이하입니다.
- 심사관은 1명 이상 100,000명 이하입니다.

### 알고리즘 설계

이미 풀어본 문제라 접근법(이분 탐색)을 알고 있었지만 제한 사항부터 O(logN)보다 복잡한 알고리즘으로는 풀 수 없다고 얘기하고 있는 것 같다..

심사 받는 사람 수가 n이 되는 시간들 중 최소 시간을 찾는 이분 탐색을 진행하면 된다.

### 코드

```py
from math import floor


def solution(n, times):
    startTime, endTime = 0, 1000**6 + 1
    while startTime < endTime:
        middleTime = floor((startTime + endTime) / 2)
        total = 0
        for count in [middleTime // time for time in times]:
            total += count

        if total < n:
            startTime = middleTime + 1
        else:
            endTime = middleTime
    return startTime

```

### 시간 복잡도

**O(MlogN)**<br />
이분 탐색(O(logN))을 하며 탐색마다 심사관 수(M)만큼 덧셈 연산을 하기 때문이다.

### 느낀점 or 기억할 정보

- 이분 탐색의 startTime과 endTime을 초기화하고 업데이트하는 것은 항상 헷갈린다.<br />DP나 백트래킹처럼 설계 방법을 따로 정리해봐야겠다.
