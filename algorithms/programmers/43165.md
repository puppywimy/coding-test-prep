### 문제 분석 요약

백트래킹 문제

### 제한 사항

- 주어지는 숫자의 개수는 2개 이상 20개 이하입니다.
- 각 숫자는 1 이상 50 이하인 자연수입니다.
- 타겟 넘버는 1 이상 1000 이하인 자연수입니다.

### 알고리즘 설계

숫자 개수(N)도 적고, 숫자마다 +/-를 선택한 경우의 수를 만드는 문제이므로 백트래킹으로 풀어봐야겠다고 생각했다.

시간 복잡도는 O(2^N)으로 연산량이 많지는 않다(2^20 ≒ 1,000,000).

**설계 메모**

```
count = 0

recursive(index, total):
    # BC
    if index === len(numbers):
        count++

    # 재귀함수 호출
    recursive(index + 1, total + numbers[index])
        "    (index + 1, total - numbers[index])
```

### 코드

```py
def solution(numbers, target):
    count = 0

    def recursive(index, total):
        nonlocal count

        # BC
        if index == len(numbers):
            if total == target:
                count += 1
            return

        # 재귀함수 호출
        recursive(index + 1, total + numbers[index])
        recursive(index + 1, total - numbers[index])

    recursive(0, 0)
    return count
```

### 시간 복잡도

**O(2^N)**<br />
백트래킹의 시간 복잡도는 경우의 수와 동일하기 때문이다.<br />
경우의 수는 2개(+/-)를 N(숫자 개수)만큼 중복해서 선택하는 경우의 수이다.

### 느낀점 or 기억할 정보
