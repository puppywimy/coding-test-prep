### 문제 분석 요약

개인적으로 좀 어려웠던 DP 문제

### 제한 사항

- N은 1 이상 9 이하입니다.
- number는 1 이상 32,000 이하입니다.
- 수식에는 괄호와 사칙연산만 가능하며 나누기 연산에서 나머지는 무시합니다.
- 최솟값이 8보다 크면 -1을 return 합니다.

### 알고리즘 설계

이것저것 해보다가 `D[i] = i개의 N으로 만들 수 있는 숫자`로 테이블 정의를 하면 어떨까 생각이 들었고 그렇게 30분을 모두 태웠다..

이후 GPT가 방향을 알려줬는데 막상 i가 증가할수록 만들 수 있는 숫자가 기하급수적으로 느는 것이었다. 그래서 먼저 시간복잡도를 구해보려고 했다.

테이블의 각 요소가 저장하는 수의 범위를 구하면 배열의 크기도 어림잡을 수 있지 않을까 생각했다. 예를 들어 `D[5] = [0, 1, 10, 25, 55]`에서 55가 가장 크므로 대충 -55~55가 저장하는 수의 범위가 되고, 이게 곧 시간 복잡도가 되지 않을까 하고..

그렇다면 N^8이 가장 크겠구나, 최대 연산량은 양수 범위만 대략 `9^8 = 3^16 < 4^16 = 2^32`... 엄청 컸다.

사실 내가 처음에 잘못 계산했다 ㅋ

`9^8 = 81^4 ~= 6400^2 ~= 4천만`은 99999999보다 훨씬 작았다. 따라서 **최대 연산량은 크게 잡아도 2억을 넘기 어려울 것**이라고 생각했다. 즉, 안전한 풀이다.

당시 문제 풀 때는 시간 복잡도만 고려하고 바로 풀이에 들어갔는데 여기에는 DP 설계를 구체적으로 적겠다.

1. 테이블 정의

   ```
   D[i] = i개의 N으로 만들 수 있는 숫자
   ```

2. 점화식 찾기

   ```
   D[i] = i는 a + b일 때,
          a + b,
          a - b,
          b - a,
          a * b,
          a / b,
          b / a,
          각 자리가 N인 i자리 수
   ```

3. 초기값 설정

   ```
   D[0]이 존재하지 않으므로
   D[1] = Set.of(N)
   ```

특별히 주의해야 할 부분은 테이블의 요소를 배열이 아닌 Set을 사용하여 중복을 최대한 없애고, 0으로 나누지 않는 것이다.

### 코드

```java
import java.util.Arrays;
import java.util.List;
import java.util.ArrayList;
import java.util.Set;
import java.util.HashSet;

class Solution {
    public int solution(int N, int number) {
        if (N == number)
            return 1;

        List<Set<Integer>> table = new ArrayList<>(
                Arrays.asList(
                        null,
                        new HashSet<Integer>(Set.of(N))));
        for (int i = 2; i <= 8; i++) {
            Set<Integer> set = new HashSet<>();
            for (int k = 1; k < i; k++) {
                for (Integer a : table.get(k)) {
                    for (Integer b : table.get(i - k)) {
                        if (a + b == number)
                            return i;
                        set.add(a + b);

                        if (a - b == number)
                            return i;
                        set.add(a - b);

                        if (b - a == number)
                            return i;
                        set.add(b - a);

                        if (a * b == number)
                            return i;
                        set.add(a * b);

                        if (b != 0) {
                            if (a / b == number)
                                return i;
                            set.add(a / b);
                        }

                        if (a != 0) {
                            if (b / a == number)
                                return i;
                            set.add(b / a);
                        }

                        int total = 0;
                        for (int j = 0; j < i; j++) {
                            total = total * 10 + N;
                        }
                        if (total == number)
                            return i;
                        set.add(total);
                    }
                }
            }
            table.add(set);
        }

        return -1;
    }
}
```

### 시간 복잡도

**O(10^M*N)**

M: -1을 반환하지 않는 최솟값
