### 문제 분석 요약

배열, 구현 ?

### 제한 사항

- prices의 각 가격은 1 이상 10,000 이하인 자연수입니다.
- prices의 길이는 2 이상 100,000 이하입니다.

### 알고리즘 설계

문제를 이해하는데 시간이 좀 걸렸다...

이중 for 문으로 구현하면 시간 복잡도가 O(n^2)이 되어버려서 제한 사항 내 풀 수 없을 거라 생각했다. 하지만 도저히 더 낮은 복잡도의 풀이가 떠오르지가 않았고 밑져야 본전이니 이중 for 문으로 구현했다.

i가 점점 증가하며 두 번째 for 문의 순회 범위가 줄고, 떨어지는 지점에서 바로 break를 해서 최적화가 됐는지 통과는 했다.

### 코드

```java
class Solution {
    public int[] solution(int[] prices) {
        int[] answer = new int[prices.length];
        for (int i = 0; i < prices.length; i++) {
            int count = 0;
            for (int j = i + 1; j < prices.length; j++) {
                count++;
                if (prices[j] < prices[i]) break;
            }
            answer[i] = count;
        }
        return answer;
    }
}
```

### 시간 복잡도

$$O(n^2)$$
