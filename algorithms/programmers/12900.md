### 문제 분석 요약

DP 문제

### 제한 사항

- 가로의 길이 n은 60,000이하의 자연수입니다.
- 경우의 수가 많아질 수 있으므로, 경우의 수를 1,000,000,007으로 나눈 나머지를 return해주세요.

### 알고리즘 설계

이번에는 백트래킹으로 모든 경우의 수를 다 구해보려고 했는데 정확한 경우의 수(시간 복잡도)를 알 수 없어 DP로 풀었다. (1,000,000,007로 나눌 정도면 효율적인 풀이는 아닌 것 같다.)<br />
DP 풀이의 시간 복잡도는 O(N)이므로 효율적으로 풀 수 있을 것이라 생각했다.

이 문제를 해석해보면 n을 "+1"과 "+2"로 구성된 수식으로 나타내는 방법의 수를 구하는 문제이다.

1. 테이블 정의

   ```
   D[i] = i를 마지막이 "+1"로 끝나거나 "+2"로 끝나는 수식으로 나타내는 방법의 수
   ```

2. 점화식 세우기

   ```
   D[i] = D[i - 1] + D[i - 2]
   ```

3. 초기값 설정

   `D[1]`과 `D[2]`를 점화식으로 구할 수 없으므로, `D[1] = 1`, `D[2] = 2`

### 코드

```js
function solution(n) {
  const denominator = 1000000007;

  const table = [null, 1, 2];
  for (let i = 3; i <= n; i++) {
    table[i] = (table[i - 1] + table[i - 2]) % denominator;
  }
  return table[n];
}
```

### 시간 복잡도

**O(N)**
