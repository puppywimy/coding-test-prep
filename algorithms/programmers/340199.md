### 제한 사항

- `wallet`의 길이 = `bill`의 길이 = 2
- 10 ≤ `wallet[0]`, `wallet[1]` ≤ 100
- 10 ≤ `bill[0]`, `bill[1]` ≤ 2,000

### 알고리즘 설계

bill이 wallet에 들어갈 때까지 다음 연산을 반복한다.

1. bill의 큰 변을 반으로 정수 나눗셈을 한다.
2. answer 값 1 증가
   이후 접은 횟수(answer)를 반환한다.

### 코드

```py
def solution(wallet, bill):
    answer = 0
    while not (
        (bill[0] <= wallet[0] and bill[1] <= wallet[1])
        or (bill[0] <= wallet[1] and bill[1] <= wallet[0])
    ):
        if bill[0] > bill[1]:
            bill[0] = bill[0] // 2
        else:
            bill[1] = bill[1] // 2
        answer += 1
    return answer
```

### 시간 복잡도

**O(log(B/W))**<br />
W \* 2^x = B<br />
-> 2^x = B/W<br />
-> x = log(B/W)
