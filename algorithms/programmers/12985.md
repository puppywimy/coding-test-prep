### 문제 분석 요약

구현 문제

### 제한 사항

- N : 2^1 이상 2^20 이하인 자연수 (2의 지수 승으로 주어지므로 부전승은 발생하지 않습니다.)
- A, B : N 이하인 자연수 (단, A ≠ B 입니다.)

### 알고리즘 설계

처음에는 어떻게 풀어야할지 막막했는데, 그림을 그리고 내가 사고한 과정을 되짚어보니 규칙이 보였다.

<img width="750" alt="image" src="https://github.com/user-attachments/assets/34c63928-f126-4d9c-9796-1bef36957f11" />

각 번호를 2로 나누고 ceil 함수를 적용하면 해당 라운드에서 경쟁하는 참가자가 같은 번호로 묶인다.<br />
ex. `3, 4 -> 2`, `7, 8 -> 4`<br />
이를 반복하며 A와 B가 같은 번호로 묶이는 시점(서로 붙게 되는 시점)을 찾으면 된다.

시간 복잡도는, 최악의 경우 마지막 라운드에 붙는 경우이므로 O(logN)이다.<br />
고로 안전하게 풀 수 있다.

### 코드

```py
import math


def solution(n, a, b):
    newA, newB = a, b
    for round in range(1, 20 + 1):
        newA, newB = math.ceil(newA / 2), math.ceil(newB / 2)
        if newA == newB:
            return round
```

### 시간 복잡도

**O(logN)**<br />
라운드의 최댓값이 logN이기 때문

### 느낀점 or 기억할 정보

- ceil이랑 floor는 math를 import해야 사용할 수 있다.
