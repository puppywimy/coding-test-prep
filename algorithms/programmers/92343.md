### 문제 분석 요약

이진 트리 탐색인데 풀이를 아직 모르겠음.

### 제한 사항

- 2 ≤ `info`의 길이 ≤ 17
  - `info`의 원소는 0 또는 1 입니다.
  - info[i]는 i번 노드에 있는 양 또는 늑대를 나타냅니다.
  - 0은 양, 1은 늑대를 의미합니다.
  - info[0]의 값은 항상 0입니다. 즉, 0번 노드(루트 노드)에는 항상 양이 있습니다.
- `edges`의 세로(행) 길이 = `info`의 길이 - 1
  - `edges`의 가로(열) 길이 = 2
  - `edges`의 각 행은 [부모 노드 번호, 자식 노드 번호] 형태로, 서로 연결된 두 노드를 나타냅니다.
  - 동일한 간선에 대한 정보가 중복해서 주어지지 않습니다.
  - 항상 하나의 이진 트리 형태로 입력이 주어지며, 잘못된 데이터가 주어지는 경우는 없습니다.
  - 0번 노드는 항상 루트 노드입니다.

### 알고리즘 설계

(잘못된 풀이)<br />
처음에 늑대를 모으는 것은 생각하지 않고 잘못된 풀이로 시도하였다.<br />
트리를 순회하여 모든 양 노드마다 도달하기 위해 필요한 양의 수를 requiredSheepCount 배열에 저장하고 이를 정렬하여 모을 수 있는 양의 수를 계산해보려고 했다.<br />
그러나 이 방법은 늑대가 누적되는 것을 고려하지 않는 방법이다.

그래서 BFS로 트리를 순회하며 visited 및 sheepCount, wolfCount 정보를 업데이트하는 방법을 고안했다.<br />
하지만 탐색 중인 노드가 늑대인 경우 어떻게 처리해야하지 떠오르지 않았다.

트리를 한 번 정제하고 푸는 과정을 생각해보다가 시간을 너무 많이 써서 여기까지 기록하고 다시 풀어볼 생각이다.

(뭔가 DFS로 풀고 늑대인 경우 끝까지 들어갔다가 양에 도달할 수 없으면 임시 저장해놓은 부모 노드로 돌아가는 방식으로 풀면 방향이 잡힐 거 같다.)

### 코드

```py
from collections import deque

def solution(info, edges):
    tree = [{'parent': None, 'children': [], 'type': info[i]} for i in range(len(info))]
    for [parent, child] in edges:
        tree[parent]['children'].append(child)
        tree[child]['parent'] = parent
    queue = deque([0])
    visited = [False for _ in info]
    sheepCount, wolfCount = 1, 0
    while len(queue):
        node = queue.popleft()
        for child in tree[node]['child']:
            if visited[child]:
                continue
            if tree[child]['type'] == 1:
                sheepCount += 1
                queue.append(child)
                visited[child] = True
            elif tree[child]['type'] == 0:
```
