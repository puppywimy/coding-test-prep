### 문제 분석 요약

다중 조건 정렬 문제?

### 제한 사항

- 1 ≤ `scores`의 길이 ≤ 100,000
- `scores`의 각 행은 한 사원의 근무 태도 점수와 동료 평가 점수를 나타내며 [a, b] 형태입니다.
  - `scores`\[0]은 완호의 점수입니다.
  - 0 ≤ a, b ≤ 100,000
- 완호가 인센티브를 받지 못하는 경우 -1을 return 합니다.

### 알고리즘 설계

인센티브를 받지 못하는 점수를 일일이 계산하면 O(N^2)의 시간 복잡도를 갖게 되므로, `scores`의 길이가 100,000까지 가능한 제한 사항으로는 시간 내 풀기 어려울 것이라 생각했다.<br />
따라서 사전 정렬을 통해 한 번만 순회하며 결과를 구할 수 있도록 구현해야 한다.

1. **a로 먼저 내림차순 정렬하고, b로 오름차순 정렬한다.**

   그렇게 하면 정렬된 점수를 순회하며 인센티브를 못 받는 점수를 탐색할 때, 현재 a가 앞선 그룹(a가 동일한 그룹)의 a보다 항상 작기 때문에, 앞선 그룹들의 최대 b 값보다 작은지만 비교하면 된다.

2. **순회**

   1. 그룹이 달라지면 groupNumber와 groupMax를 업데이트 (groupMax를 쉽게 업데이트하기 위해 b로 오름차순 정렬한 것)
   2. b가 groupMax보다 작다면 a, b가 모두 작은 경우이므로 탈락 (그게 원호라면 -1 반환)
   3. 인센티브를 받을 수 있는 점수 배열인 goodScores에 저장

3. **goodScores를 정렬하고 원호의 순위 반환**

### 코드

```py
def solution(scores):
    wanhoScore = scores[0]
    sortedScores = sorted(scores, key=lambda x: (-x[0], x[1]))
    groupNumber = sortedScores[0][0]
    groupMax = 0
    goodScores = []
    for i in range(len(sortedScores)):
        score = sortedScores[i]

        # 다음 그룹으로
        if groupNumber != score[0]:
            groupNumber = score[0]
            groupMax = max(groupMax, sortedScores[i - 1][1])

        if score[1] < groupMax:
            if score == wanhoScore:
                return -1
            continue
        goodScores.append(score)
    totalScores = [a + b for [a, b] in goodScores]
    sortedTotalScores = sorted(totalScores, reverse=True)
    wanhoTotalScore = wanhoScore[0] + wanhoScore[1]
    for i in range(len(sortedTotalScores)):
        totalScore = sortedTotalScores[i]
        if totalScore == wanhoTotalScore:
            return i + 1
```

### 시간 복잡도

**O(NlogN)**<br />
정렬 시간 복잡도가 순회 시간 복잡도보다 크므로

### 느낀점 or 기억할 정보

- a로 정렬하는 것까지는 떠올렸는데 이후 어떻게 풀어야할지 막막했다.
- python의 다중 조건 정렬
  - `sorted(scores, key=lambda x: (-x[0], x[1]))`
  - 시간 복잡도는 O(NlogN \* 조건 개수), 즉 동일하게 O(NlogN)
- 다른 사람의 풀이를 보니 goodScores 배열을 따로 만들 필요 없이 순회 단계에서 원호 앞에 있는 점수만 세는 방식으로도 풀 수 있다.
