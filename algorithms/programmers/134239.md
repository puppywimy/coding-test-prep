### 제한사항

- 2 ≤ k ≤ 10,000
- 1 ≤ ranges의 길이 ≤ 10,000
  - ranges의 원소는 [a, b] 형식이며 0 ≤ a < 200, -200 < b ≤ 0 입니다.
- 주어진 모든 입력에 대해 정적분의 결과는 227 을 넘지 않습니다.
- 본 문제는 정답에 실수형이 포함되는 문제입니다. 입출력 예의 소수 부분 .0이 코드 실행 버튼 클릭 후 나타나는 결괏값, 기댓값 표시와 다를 수 있습니다.

### 알고리즘 설계

우선 다음 시나리오대로 구현을 계획하고 구현했다.

1. 우박 수열 구하기. 시간 복잡도 모름(?)
2. b 양수 변환 및 범위 Validation
3. 정적분 결과 구하기. b-a번 연산을 수행하므로 시간 복잡도는 O(b-a)

### 코드

```py
def solution(k, ranges):
    result = []

    # 1. 우박 수열 구하기
    f = []
    i = 0
    while k > 1:
        f.append(k)
        if k % 2:
            k = k * 3 + 1
        else:
            k = k // 2
        i += 1
    f.append(k)

    # 2. b 양수 변환 및 범위 Validation
    for [a, b] in ranges:
        b += len(f) - 1
        if a < b:
            # 3. 정적분 결과 구하기
            total = 0
            for x in range(a, b):
                x1 = x
                x2 = x + 1
                if f[x1] == f[x2]:
                    total += f[x1]
                    continue
                bigNumber = f[x1] if f[x1] > f[x2] else f[x2]
                smallNumber = f[x2] if f[x1] > f[x2] else f[x1]
                triangle = (bigNumber - smallNumber) / 2
                square = smallNumber
                total += triangle + square
            result.append(total)
        elif a > b:
            result.append(-1)
        else:
            result.append(0)
    return result
```

### 시간 복잡도

우박 수열을 구하는 시간 복잡도와 O(b-a) 중 큰 것.<br />
그러나 우박 수열을 구하는 시간 복잡도를 계산해보지 않았다..

### 느낀점 or 기억할 정보

정적분 계산할 때 잘못 구현해서 시간을 좀 잡아먹었다.
