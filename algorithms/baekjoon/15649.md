### 문제 분석 요약
백트래킹을 통해 모든 경우를 출력하는 문제

### 알고리즘 설계
조건
- 1 <= M <= N <= 8

1. **함수 정의**
   ```py
   instances = [1, 2, 3] # 재료 배열
   isUsed = [False, False, False] # 해당 재료가 사용되었는지 여부
   result = [None, None, None] # 결과 배열
   
   def recursive(현재 인덱스): # ...
   ```
2. **Base Condition**

   현재 인덱스가 M과 같다면 결과 배열을 출력하고 다른 후보군 탐색
3. **재귀 식**
   ```py
   def recursive(index):
       # 1. Base Condition

       # 2. 1 ~ N까지의 재료 중 사용되지 않은 재료로 후보군 생성
       #    결과 배열이 완성될 때까지 다음 인덱스에 대해 반복
   ```


### 코드
```py
# 제출 시 파일 입출력 부분 지우기

import sys

sys.stdin = open("input", "r")


def solution():
    N, M = map(int, input().split(" "))
    instances = [i + 1 for i in range(N)]
    isUsed = [False for _ in range(N)]
    result = [None for _ in range(M)]
    output = []

    def recursive(index):
        if index == M:
            output.append(" ".join(map(str, result)))
            return

        for i in range(N):
            if not isUsed[i]:
                result[index] = instances[i]
                isUsed[i] = True
                recursive(index + 1)
                isUsed[i] = False

    recursive(0)
    print("\n".join(output))


solution()
```

### 시간 복잡도
O(N!/(N - M)! * M)

경우의 수: N!/(N - M)!, 선택한 숫자에 대해서는 탐색하지 않기 때문

출력 비용: M

### 느낀점 or 기억할 정보
- 중복이 불가한 순열이므로 O(N^M)은 너무 보수적임.
