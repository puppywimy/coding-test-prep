### 문제 분석 요약

최적의 값을 이분 탐색하는 문제

### 알고리즘 설계

조건

- 1 <= N <= 1,000,000, 1 <= M <= 2,000,000,000, 0 <= 각 나무의 높이 <= 1,000,000,000
- 파이썬은 int 오버플로우가 없으므로 탐색 시 나무의 최대 합은 고려하지 않아도 된다. (500,000,000 \* 1,000,000)

설계

- [0, 1,000,000,000] 범위를 탐색
- 값을 찾지 못 할 수 있음. (최댓값 찾기)

### 코드

```py
# 제출 시 파일 입출력 부분 지우기

import sys

sys.stdin = open("input", "r")

import math


def solution():
    N, M = map(int, input().split(" "))
    treeHeights = list(map(int, input().split(" ")))
    startHeight = 0
    endHeight = 1000000000 + 1
    maxHeight = 0
    while startHeight < endHeight:
        currentHeight = math.floor((startHeight + endHeight) / 2)
        total = 0
        for height in treeHeights:
            total += height - currentHeight if height >= currentHeight else 0
        if total > M:
            maxHeight = currentHeight
            startHeight = currentHeight + 1
        elif total < M:
            endHeight = currentHeight
        else:
            maxHeight = currentHeight
            break
    print(maxHeight)


solution()
```

### 시간 복잡도

O(Nlog(나무의 최대 높이)), 이분 탐색으로 [0, 나무의 최대 높이] 범위를 탐색하고, 각 과정에서 N그루의 나무에 대해 계산

### 느낀점 or 기억할 정보

- 디버깅용 `print()`문을 지우는 것을 잊지 말자..
- `startHeight = currentHeight + 1`로 작성해야 무한 루프에 빠지지 않음.
- `maxHeight`를 이용해 탐색을 실패해도 최댓값을 찾도록 함.
