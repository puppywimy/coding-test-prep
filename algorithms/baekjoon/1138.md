### 문제 분석 요약

키가 작은 사람부터 자리를 선점해야 하는 그리디 알고리즘

### 제한사항

- 1 ≤ N ≤ 10
- i번째 수는 0보다 크거나 같고, N-i보다 작거나 같다. i는 0부터 시작한다.

### 알고리즘 설계

처음에는 문제 이해가 잘 안 돼서 예시를 규칙대로 그려보면서 이해를 하고자 했다.

예제 입력 4

```
7
6 1 1 1 2 0 0
```

그려보니 다음과 같은 과정으로 그림을 그렸다는 것을 알게 되었다.

1. line 배열을 만든다.
2. 작은 키부터 다음 작업을 반복한다.
   1. line 배열의 왼쪽에서 출발하여 빈칸 개수가 "왼쪽에 있는 자기보다 큰 사람 수"와 같아질 때까지 오른쪽으로 이동한다.
   2. 해당 위치에 자리를 잡는다.

이렇게 풀 수 있는 이유는 작은 키부터 자리를 선점했기 때문이다.<br />
이미 자리를 잡고 있는 사람은 본인보다 작은 사람이므로 고려하지 않아도 된다.<br />
즉, 본인보다 큰 사람들을 위한 빈칸 개수만 남겨놓고 자리를 잡으면 된다는 뜻이다.

### 코드

```js
const fs = require("fs");
const rawInput = fs.readFileSync("input").toString().trim(); // fs.readFileSync(0, "utf-8").trim();

function solution() {
  const counts = rawInput.split("\n")[1].split(" ").map(Number);
  const line = Array.from({ length: counts.length }).fill(null);
  for (let i = 0; i < counts.length; i++) {
    const targetCount = counts[i];
    const currentHeight = i + 1;

    let count = 0;
    for (let j = 0; j < line.length; j++) {
      if (line[j] === null && count++ === targetCount) line[j] = currentHeight;
    }
  }
  console.log(line.join(" "));
}

solution();
```

### 시간 복잡도

**O(N^2)**<br />
N개의 키에 대해 크기가 N인 배열(line)을 순회하기 때문<br />
(순회 횟수가 "1 + 2 + 3 + ... + N"이지만 결국 N^2이다.)
