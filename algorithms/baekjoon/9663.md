### 문제 분석 요약
백트래킹을 통해 가능한 경우의 수를 세는 문제

### 알고리즘 설계
조건
- 1 <= N < 15

1. **함수 정의**
   ```py
   isUsedColumn # 해당 열이 사용 중인지 여부
   isUsedSlash # 해당 상향 대각선("/")이 사용 중인지 여부
   isUsedBackslash # 해당 하향 대각선("\")이 사용 중인지 여부

   count # 경우의 수
   
   def recursive(현재 행 인덱스): # ...
   ```
2. **Base Condition**

   현재 행 인덱스가 N과 같다면 마지막 퀸(행: N - 1)까지 배치가 가능한 경우로, count를 1 증가시키고 다른 후보군 탐색
3. **재귀 식**
   ```py
   def recursive(rowIndex):
       # 1. Base Condition

       # 2. 0 ~ N - 1까지의 열 인덱스를 i라 했을 때,
       #    좌표 (i, rowIndex)에 대해 배치 가능한지 확인 후 탐색
   ```


### 코드
```py
# 제출 시 파일 입출력 부분 지우기

import sys

sys.stdin = open("input", "r")


def solution():
    N = int(input())

    # -
    isUsedColumn = [False for _ in range(N)]
    # /
    isUsedSlash = [False for _ in range(2 * N - 1)]
    # \
    isUsedBackslash = [False for _ in range(2 * N - 1)]

    count = 0

    def recursive(rowIndex):
        nonlocal count

        if rowIndex == N:
            count += 1
            return

        for i in range(N):
            columnIndex = i
            slashIndex = i + rowIndex
            backslashIndex = (i - rowIndex) + (N - 1)
            if not (
                isUsedColumn[columnIndex]
                or isUsedSlash[slashIndex]
                or isUsedBackslash[backslashIndex]
            ):
                isUsedColumn[columnIndex] = True
                isUsedSlash[slashIndex] = True
                isUsedBackslash[backslashIndex] = True
                recursive(rowIndex + 1)
                isUsedColumn[columnIndex] = False
                isUsedSlash[slashIndex] = False
                isUsedBackslash[backslashIndex] = False

    recursive(0)
    print(count)


solution()
```

### 시간 복잡도
강의에서는 "가지치기"가 빈번할 수록 시간 복잡도를 가늠하기 어렵기 때문에 N 최댓값을 넣어보고 시간 초과가 되는지 확인해보라고 함.

(가지치기: 백트래킹 내부적으로 명백히 탐색할 필요가 없는 경우를 제외하는 것)

시간 복잡도는 최대 O(N!), 백트래킹으로 가지치기가 되면 실제로는 더 낮을 수 있음.

### 느낀점 or 기억할 정보
탐색 과정에서 현재 좌표가 사용 중인지 매번 x + y, x - y를 계산하는 것보다 used 배열을 사용하면 최적화할 수 있다. used 배열을 적절하게 설계하는 것이 중요한 것 같다.
