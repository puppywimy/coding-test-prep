### 문제 및 풀이 날짜

- https://www.acmicpc.net/problem/10811
- 2025-12-01

### 문제 분석 요약

간단한 구현 문제

### 제한사항

- 1 ≤ N ≤ 100
- 1 ≤ M ≤ 100
- 1 ≤ i ≤ j ≤ N

### 알고리즘 설계

문제대로 구현한다고 했을 때,<br />
역순으로 바꾸는 시간 복잡도는 O(범위 길이)이고, 총 M번 수행하므로 전체 시간 복잡도는 O(NM)이다.<br />

### 코드

```py
def solution():
    N, M = map(int, input().split(" "))
    baskets = list(range(1, N + 1))
    for _ in range(M):
        i, j = map(int, input().split(" "))
        baskets[i - 1 : j] = reversed(baskets[i - 1 : j])
    print(" ".join(map(str, baskets)))


solution()
```

### 시간 복잡도

**O(NM)**<br />
[i, j]가 [1, N]인 경우가 최악의 경우로 역순으로 바꾸는 데 N번의 연산이 필요하다.

### 느낀점 or 기억할 정보
