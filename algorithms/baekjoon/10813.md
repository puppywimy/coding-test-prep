### 문제 및 풀이 날짜

- https://www.acmicpc.net/problem/10813
- 2025-11-21

### 문제 분석 요약

구현 문제

### 제한사항

- 1 ≤ N ≤ 100
- 1 ≤ M ≤ 100

### 알고리즘 설계

출력 비용은 O(N), 교환 비용은 O(1)이고 M번 반복하므로 시간 복잡도는 O(max(N, M))이다.<br />
하지만 범위가 매우 작기 때문에(100 이하) 크게 중요하지 않았다.<br />
알고리즘은 그냥 구현하면 된다.

### 코드

```py
def solution():
    N, M = map(int, input().split(" "))
    balls = [i for i in range(N + 1)]  # 1-based indexing
    for _ in range(M):
        i, j = map(int, input().split(" "))
        balls[i], balls[j] = balls[j], balls[i]
    print(" ".join(map(str, balls[1:])))


solution()
```

### 시간 복잡도

**O(max(N, M))**
