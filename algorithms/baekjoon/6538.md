### 알고리즘 설계

규칙

1. 2~9개의 연속되는 동일한 문자는 f'{개수}{문자}'로 인코딩
2. 9개 이상의 연속되는 동일한 문자는 앞에서부터 9개씩 끊어서 규칙 적용
3. 연속되는 동일하지 않은 문자는 f'1{문자들}1'로 인코딩
4. 3번에서 문자가 1이면 11로 대체 ex. 123 -> 111231

sameCharacters, differentCharacters, previousCharacter로 상태를 저장하고,<br />
분기를 다음과 같이 나누었다.<br />

1. <i>이전 문자와 현재 문자가 같은 경우, differentCharacters에 요소가 존재하면</i>

   differentCharacters의 인코딩을 진행하고 sameCharacters의 인코딩을 준비한다.

   이때 sameCharacters 길이가 9가 되면 2번 규칙에 의해 바로 인코딩을 준비한다.

2. <i>이전 문자와 현재 문자가 같은 경우, differentCharacters에 요소가 존재하지않으면</i>

   그냥 sameCharacters의 인코딩을 준비한다.

3. <i>이전 문자와 현재 문자가 다른 경우, sameCharacters에 요소가 존재하면</i>

   이전 문자는 이전이전 문자와 같은 경우이므로(sameCharacters 인코딩을 준비했으므로) sameCharacters 인코딩을 이전 문자를 포함해서 진행한다.

4. <i>이전 문자와 현재 문자가 다른 경우, sameCharacters에 요소가 존재하지않으면</i>

   differentCharacters의 인코딩을 준비한다.

마지막에 남아있는 sameCharacters, differentCharacters, previousCharacter 마무리 작업도 잊지 않고 해주었다.

### 코드

```py
def solution():
    while True:
        string = ""
        try:
            string = input()
        except:
            break
        characters = list(string)
        sameCharacters = []
        differentCharacters = []
        # 빈 줄 처리
        if not len(characters):
            print("")
            continue
        previousCharacter = characters[0]
        encodedString = ""
        for character in characters[1:]:
            if previousCharacter == character:
                if len(differentCharacters):
                    encodedString += f"1{''.join(differentCharacters)}1"
                    differentCharacters = []
                sameCharacters.append(previousCharacter)
                # 9개에서 끊기
                if len(sameCharacters) == 9:
                    encodedString += f"9{previousCharacter}"
                    sameCharacters = []
            else:
                if len(sameCharacters):
                    encodedString += f"{len(sameCharacters) + 1}{previousCharacter}"
                    sameCharacters = []
                else:
                    differentCharacters.append(
                        previousCharacter if previousCharacter != "1" else "11"
                    )
            previousCharacter = character
        if len(sameCharacters):
            encodedString += f"{len(sameCharacters) + 1}{previousCharacter}"
        elif len(differentCharacters):
            encodedString += f"1{''.join(differentCharacters)}{previousCharacter if previousCharacter != '1' else '11'}1"
        else:
            encodedString += (
                f"1{previousCharacter if previousCharacter != '1' else '11'}1"
            )
        print(encodedString)


solution()
```
