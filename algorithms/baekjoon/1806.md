### 문제 및 풀이 날짜

- https://www.acmicpc.net/problem/1806
- 2025-11-03

### 문제 분석 요약

투포인터를 이용해 합이 특정 값 이상이 되는 연속된 수 길이 중 최솟값 탐색

### 제한사항

- 10 ≤ N < 100,000
- 0 < S ≤ 100,000,000
- 0 < numbers\[i] ≤ 10,000

### 알고리즘 설계

투포인터 알고리즘으로 부분합을 업데이트하며 탐색하는 방식으로 풀 수 있을 것 같았다.<br />
투포인터를 이용한 탐색 시간 복잡도는 2N = 200,000이므로 안전하게 풀 수 있다.

### 코드

```js
const fs = require("fs");
const rawInput = fs.readFileSync(0, "utf-8").trim();

function solution() {
  const [[N, S], numbers] = rawInput
    .split("\n")
    .map((row) => row.split(" ").map(Number));
  let cursor1 = 0;
  let cursor2 = 1;
  let total = numbers[cursor1];
  let min = 100000;
  while (cursor2 <= N) {
    if (total < S) {
      total += numbers[cursor2++];
      continue;
    }
    let length = cursor2 - cursor1;
    if (length < min) min = length;
    total -= numbers[cursor1++];
  }
  console.log(min === 100000 ? 0 : min);
}

solution();
```

### 시간 복잡도

**O(N)**
