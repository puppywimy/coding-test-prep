### 문제 분석 요약

백트래킹으로 모든 조합의 결과를 구하고, 각 결과에서 문제에서 요구하는 최솟값을 계산하는 문제

### 알고리즘 설계

조건

- 2 <= N <= 50, 1 <= M <= 13
- 1 <= 집의 수 H <= 2N, M <= 치킨집의 수 I <= 13

시간 복잡도를 계산해보면

1. 입력 받기: N \* N = 2,500
2. 조합의 수: 13C6 = 1,716
3. 각 집에서 치킨 거리 구하기: 2N \* M = 100 \* 13 = 1,300

2,500 + 1,716 \* 1,300 = 약 2,000,000<br />
따라서 백트래킹으로 풀 수 있음.

1. 사전 준비

   ```js
   const houses = []; // 집의 좌표 저장
   const chickenJoints = []; // 치킨집의 좌표 저장
   const isUsed = []; // 조합에 사용
   let min = 9800; // 최대 치킨 거리는 (49 - 0) + (49 - 0) = 98이라
   // 그냥 최대 H를 곱해줬음.

   // [startIndex, endIndex] 범위 내에서 선택
   function recursive(startIndex, endIndex) {
     /* ... */
   }
   ```

2. Base Condition

   endIndex가 chickenJoints.length보다 커졌다는 것은 M개의 선택을 완료했다는 의미<br />
   따라서 이때의 결과로 치킨 거리와 도시의 치킨 거리 계산

3. 재귀 함수

   ```js
   function recursive(startIndex, endIndex) {
     // Base Condition
     //
     // [startIndex, endIndex] 범위 내에서 치킨집 선택(isUsed[i] = true)
     // recursive(i + 1, endIndex + 1)
     // isUsed[i] = false
   }
   ```

### 코드

```js
const fs = require("fs");
const rawInput = fs.readFileSync("input").toString().trim(); // fs.readFileSync(0, "utf-8").trim();

function solution() {
  const [[N, M], ...map] = rawInput
    .split("\n")
    .map((row) => row.split(" ").map(Number));
  const houses = [];
  const chickenJoints = [];
  for (let i = 0; i < N; i++) {
    for (let j = 0; j < N; j++) {
      if (map[i][j] === 1) houses.push([i, j]);
      if (map[i][j] === 2) chickenJoints.push([i, j]);
    }
  }
  const isUsed = chickenJoints.map(() => false);
  let min = 9800;

  function recursive(startIndex, endIndex) {
    if (endIndex > chickenJoints.length) {
      let total = 0;
      for (let i = 0; i < houses.length; i++) {
        let chickenDistance = 98;
        for (let j = 0; j < chickenJoints.length; j++) {
          if (!isUsed[j]) continue;
          const distance =
            Math.abs(houses[i][0] - chickenJoints[j][0]) +
            Math.abs(houses[i][1] - chickenJoints[j][1]);
          if (distance < chickenDistance) chickenDistance = distance;
        }
        total += chickenDistance;
      }
      if (total < min) min = total;
      return;
    }

    for (let i = startIndex; i < endIndex; i++) {
      isUsed[i] = true;
      recursive(i + 1, endIndex + 1);
      isUsed[i] = false;
    }
  }

  recursive(0, chickenJoints.length - (M - 1));
  console.log(min);
}

solution();
```

### 시간 복잡도

N^2 + MC[M/2] _ 2N _ M

### 느낀점 or 기억할 정보

- 조합의 최댓값 = MC[M/2]
- js에는 C++의 next_permutation 같은 라이브러리가 없어서 백트래킹으로 구현하는 연습이 좀 필요할 것 같다.
