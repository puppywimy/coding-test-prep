### 문제 분석 요약

조합 구하기

### 알고리즘 설계

조건

- 0 < N <= M < 30

조합을 구하면 되었기에 팩토리얼을 계산하는 방식으로 풀었다.

### 코드

```py
def solution():
    T = int(input())
    for _ in range(T):
        N, M = map(int, input().split(" "))
        numerator = 1
        for i in range(M, M - N, -1):
            numerator *= i
        denominator = 1
        for i in range(N, 1, -1):
            denominator *= i
        print(int(numerator / denominator))


solution()
```

### 시간 복잡도

O(N), 분모와 분자를 구할 때 각각 N번씩 곱셈이 수행되기 때문
