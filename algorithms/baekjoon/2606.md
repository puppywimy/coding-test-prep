### 문제 분석 요약
1번 노드부터 시작해 연결된 노드를 모두 탐색하는 문제

### 알고리즘 설계
조건
- 0 < computerCount <= 100(따라서 0 <= edgeCount <= 4950)

BFS를 이용해 1번 노드부터 연결된 모든 노드를 탐색한다.

1. edges를 이용하여, 특정 노드 번호를 이용하여 해당 노드에 연결된 노드를 확인할 수 있는 객체를 만든다. (connectionData)
2. queue 선언 및 1번 노드 삽입
3. visited 선언 및 1번 노드 체크
4. BFS 구현 - queue에서 꺼낸 노드 번호로 연결된 노드들 확인(connectionData[currentIndex]), 각 연결된 노드들에 대해 다음을 수행
   - visited가 true라면 이미 방문한 노드로 continue
   - 1번 노드와 연결된 노드로 감염됨, count 증가
   - 해당 노드를 queue에 넣고 visited 체크

### 코드
```js
const fs = require("fs");
const rawInput = fs.readFileSync("input").toString().trim(); // fs.readFileSync(0, "utf-8").trim();

function solution() {
  const [[computerCount], [edgeCount], ...edges] = rawInput
    .split("\n")
    .map((row) => row.split(" ").map(Number));
  const connectionData = Array.from({ length: computerCount + 1 }).map(
    () => []
  );
  for (let i = 0; i < edgeCount; i++) {
    const [index1, index2] = edges[i];
    connectionData[index1].push(index2);
    connectionData[index2].push(index1);
  }
  const queue = [1];
  const visited = Array.from({ length: computerCount + 1 }).map(() => false);
  let count = 0;
  visited[queue[0]] = true;
  while (queue.length) {
    const currentIndex = queue.shift();
    for (let i = 0; i < connectionData[currentIndex].length; i++) {
      const newIndex = connectionData[currentIndex][i];
      if (visited[newIndex]) continue;
      count++;
      queue.push(newIndex);
      visited[newIndex] = true;
    }
  }
  console.log(count);
}

solution();
```

### 시간 복잡도
O(max(computerCount, edgeCount))
- connectionData 계산: O(max(computerCount, edgeCount))
- BFS: O(감염된 컴퓨터 수)
- 감염된 컴퓨터 수는 항상 computerCount보다 작거나 같으므로
- O(max(computerCount, edgeCount))
