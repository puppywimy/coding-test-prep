### 문제 분석 요약

2차원 DP 문제?

### 제한 사항

- 1 ≤ n ≤ 10,000
- 0 ≤ 포도주의 양 ≤ 1,000

### 알고리즘 설계

오랜만에 DP 문제를 풀어서 풀이를 깔끔하게 떠올리지 못했다.<br />
1칸 또는 2칸을 뛰어올라가는 계단 문제와 비슷하다고 생각했는데 계단 문제 풀이가 잘 떠오르지 않았다.

1. 테이블 정의

   ```
   D[i][0] = i번째 포도주를 마시지 않았을 때의 총 포도주 양의 최댓값
   D[i][1] = i번째 포도주를 마셨을 때, 연속하지 않은 경우 총 포도주 양의 최댓값
   D[i][2] = i번째 포도주를 연속으로 마신 경우 총 포도주 양의 최댓값
   ```

2. 점화식 세우기

   ```
   D[i][0] = max(D[i - 1][0], D[i - 1][1], D[i - 1][2])
   D[i][1] = S[i] + D[i - 1][0]
   D[i][2] = S[i] + D[i - 1][1]
   ```

3. 초기값 설정

   ```
   D[0] = [0, S[0], S[0]]
   D[1] = [S[0], S[1], S[0] + S[1]]
   ```

### 코드

```py
def solution():
    maxWineCounts = 10000

    N = int(input())
    amounts = [int(input()) for _ in range(N)]

    if N == 1:
        print(amounts[0])
        return

    table = [None] * N
    table[0] = [0, amounts[0], amounts[0]]
    table[1] = [amounts[0], amounts[1], amounts[0] + amounts[1]]
    for i in range(2, N):
        table[i] = [
            max(table[i - 1]),
            table[i - 1][0] + amounts[i],
            table[i - 1][1] + amounts[i],
        ]

    print(max(table[N - 1]))


solution()

```

### 시간 복잡도

**O(N)**<br />
테이블을 N번 채워나가기 때문이다.
