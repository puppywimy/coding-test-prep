### 문제 및 풀이 날짜

- https://www.acmicpc.net/problem/10026
- 2026-01-01

### 문제 분석 요약

BFS

### 제한 사항

- 1 ≤ N ≤ 100

### 알고리즘 설계

구역을 나누는 전형적인 BFS 문제라고 생각했고, 적록색약 여부에 따라 각각 BFS를 한 번씩 수행하면 될 것이라고 생각했다.

연산량은 대략 10,000(입력) + 2 \* 10,000(BFS) = 30,000으로 제한 사항 내에 풀 수 있다.

코드를 작성하다보니<br />
적록색약 여부에 따라 BFS를 다르게 구현하기보다, 중간에 picture의 R과 G를 X로 통일해서 BFS를 수행하는 방법이 코드가 더 깔끔해보여서<br />
연산량이 늘어나지만 후자의 방법으로 구현하였다.

### 코드

```py
from collections import deque


def solution():
    N = int(input())
    picture = [list(input()) for _ in range(N)]

    def printAreaCounts():
        areaCounts = 0
        queue = deque([])
        visited = [[False for _ in row] for row in picture]
        dx = [-1, 1, 0, 0]
        dy = [0, 0, -1, 1]
        for startX in range(N):
            for startY in range(N):
                if visited[startX][startY] == True:
                    continue
                color = picture[startX][startY]
                queue.append((startX, startY))
                visited[startX][startY] = True
                while len(queue):
                    x, y = queue.popleft()
                    for i in range(4):
                        newX, newY = x + dx[i], y + dy[i]
                        if not ((0 <= newX and newX < N) and (0 <= newY and newY < N)):
                            continue
                        if visited[newX][newY]:
                            continue
                        if picture[newX][newY] != color:
                            continue
                        queue.append((newX, newY))
                        visited[newX][newY] = True
                areaCounts += 1
        print(areaCounts)

    printAreaCounts()
    picture = [[color if color == "B" else "X" for color in row] for row in picture]
    printAreaCounts()


solution()

```

### 시간 복잡도

**O(N^2)**<br />
BFS를 통해 그림의 각 칸을 한 번씩 순회하기 때문이다.
