### 문제 및 풀이 날짜

- https://www.acmicpc.net/problem/1715
- 2025-11-11

### 문제 분석 요약

우선 순위 큐를 활용하는 문제

### 제한사항

- 1 ≤ N ≤ 100,000
- 숫자 카드 묶음의 크기는 1,000보다 작거나 같은 양의 정수이다.

### 알고리즘 설계

비교 횟수의 계산식상, 먼저 비교되는 카드 묶음일수록 해당 카드 묶음의 크기가 누적되어 더해진다.

예를 들어 카드 묶음의 크기 A, B, C, D가 있는 경우,<br />
(`?`는 두 카드 묶음을 비교하고 합쳐서 나온 크기를 반환하는 연산자라 가정)

1. `((A ? B) ? C) ? D` -> `3A + 3B + 2C + D`
2. `(A ? C) ? (B ? D)` -> `2A + 2B + 2C + 2D`

그래서 **카드 묶음들 중 가장 작은 묶음 두 개를 골라 비교하는 과정을 반복**하는 방식으로 풀 수 있을 것이라 생각했다.<br />
가장 작은 카드 묶음 두 개를 합치고 다시 배열에 넣고 정렬을 반복하는 방식으로 구현하면 시간 복잡도가 너무 높아지므로, Heap 자료구조를 사용해서 풀고자 했다.<br />
시간 복잡도는 O(logN!)으로 O(NlogN)보다 작으므로 안전한 풀이이다..!

### 코드

```py
import heapq

def solution():
    N = int(input())
    heap = [int(input()) for _ in range(N)]
    heapq.heapify(heap)
    totalComparisonCount = 0
    while len(heap) > 1:
        comparisonCount = heapq.heappop(heap) + heapq.heappop(heap)
        totalComparisonCount += comparisonCount
        heapq.heappush(heap, comparisonCount)
    print(totalComparisonCount)


solution()
```

### 시간 복잡도

**O(log(N!))**<br />
Heap 자료구조를 이용하면 pop과 push 연산 모두 O(logN)의 시간 복잡도로 수행할 수 있다.<br />
가장 작은 두 카드 묶음을 pop하고 더해 push를 반복하므로,<br />
O(logN + logN-1 + logN-2 + ... + log1), 즉 시간 복잡도는 O(log(N!))이다.

### 느낀점 or 기억할 정보

- Python은 heapq 라이브러리를 이용해 Heap을 사용할 수 있다.
  - `heapq.heapify(array)`
  - `heapq.heappop(array)`
  - `heapq.heappush(array, x)`
