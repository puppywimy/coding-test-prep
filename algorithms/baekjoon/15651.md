### 문제 및 풀이 날짜

- https://www.acmicpc.net/problem/15651
- 2025-11-28

### 문제 분석 요약

백트래킹

### 제한사항

- 1 ≤ M ≤ N ≤ 7

### 알고리즘 설계

총 경우의 수는 N^M으로 1,000,000를 넘지 않는다(7^7 < 8^7 = 2^21).<br />
냅다 반복문 7겹을 사용해도 되지만 백트래킹으로 푸는 게 더 쉬운 것 같다.

```
def recursive(index):
    # Base Condition
    index가 M과 같아지면 경우를 완성한 것이므로 출력하고 리턴한다.

    # 재귀함수 호출
    1부터 N까지 증가하며 output의 현재 index를 업데이트한다.
    이후 다음 index 업데이트를 위해 재귀함수를 호출한다.
```

### 코드

```py
def solution():
    N, M = map(int, input().split(" "))
    output = [-1] * M

    def recursive(index):
        if index >= M:
            print(" ".join(map(str, output)))
            return

        for i in range(N):
            output[index] = i + 1
            recursive(index + 1)

    recursive(0)


solution()
```

### 시간 복잡도

**O(N^M)**<br />
`(N^(M + 1) - 1) / (N - 1)`만큼 재귀함수가 호출되기 때문이다.<br />
재귀함수 트리의 노드 개수는 `N^0 + N^1 + N^2 + ... + N^M`이고,<br />
등비 수열의 합 공식으로 계산하면 `(N^(M + 1) - 1) / (N - 1)`이다.

### 느낀점 or 기억할 정보

- 반복문으로 구현하나 백트래킹으로 구현하나 시간 복잡도는 O(N^M)이다.
